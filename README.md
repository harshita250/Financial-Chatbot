# AI-Powered Financial Chatbot — BCG GenAI Consulting Job Simulation

This repository contains the code and documentation for a job simulation completed as part of an application to BCG's GenAI Consulting team. The project involved building an AI-powered financial chatbot that interprets data from SEC filings (10-K and 10-Q) to deliver user-friendly financial insights.

## 🔍 Project Overview

The chatbot was designed to:
- Parse and interpret complex financial data from SEC filings (10-K, 10-Q)
- Use rule-based logic to respond to natural language financial queries
- Provide easy-to-understand analysis for users with limited financial knowledge

## 🛠️ Technologies Used

- **Python**: Core programming language
- **pandas**: For structured data manipulation and analysis
- **Rule-based Logic**: To simulate basic NLP response generation
- **Streamlit** *(optional)*: For an interactive user interface (if frontend was implemented)

## 📊 Key Features

- Extracts key metrics like Total Revenue, Net Income, Total Assets, Liabilities, and Cash Flow from 10-K/10-Q reports
- Transforms raw data into structured insights
- Responds to user prompts like:
  - "Show me Apple's 2024 profit margin"
  - "Compare Tesla's operating cash flow for the past 3 years"

## 🧠 Skills Demonstrated

- Real-world application of GenAI principles in consulting
- Financial data interpretation and transformation
- Python scripting and automation
- Integration of structured data for conversational use
